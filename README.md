# Tory Jarvis – Portfolio

This is my personal portfolio website showcasing my work as a software engineer, artist, and creative. It features a selection of my development projects and visual art, built with HTML, CSS, and JavaScript.

## Tech Stack

- HTML5  
- CSS3 (Custom styles and responsive design.)  
- JavaScript (Image modal functionality.)  

## Structure

- `index.html` – Homepage with bio, skills, and contact info  
- `portfolio.html` – Project and artwork showcase  
- `styles.css` – Global styles and layout  
- `portfolio.css` – Portfolio-specific styling  
- `modal.js` – Handles image modal behavior

## Features

- Mobile-responsive design  
- Dynamic image modal viewer for artwork and project screenshots  
- Clean, simple UI built from scratch

## Notes

- No frameworks used — pure front-end for full control and customization  
- Hosted locally via GitHub Pages
