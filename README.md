# Tory Jarvis – Portfolio

This is my personal portfolio website, showcasing my work as a software engineer, artist, and creative. It features a selection of my development projects, visual art, and other professional endeavors. This site was built simply with HTML, CSS (custom styles and responsive design), and JavaScript (image modal functionality).

## Structure

- `index.html` – Homepage with bio, skills, and contact info
- `portfolio.html` – Project and artwork showcase
- `styles.css` – Global styles and layout
- `portfolio.css` – Portfolio-specific styling
- `modal.js` – Handles image modal behavior

## Features

- Dynamic image modal viewer for artwork and project screenshots
- Clean, mobile-responsive design, with a simple UI built from scratch

## Notes

- No frameworks used — pure front-end.
- Hosted GitHub Pages.
