# Tory Jarvis – Portfolio

This is my personal portfolio website, showcasing my work as a software engineer. It features a selection of my development projects, and other occasional professional endeavors. This site was built simply with HTML, CSS (custom styles and responsive design), and JavaScript (image modal functionality and command palette).

## Structure

- `index.html` - Single-page site: bio, skills, dev work, contact info
- `styles.css` - Global styles and layout
- `portfolio.css` - Portfolio-specific styling
- `modal.js` - Handles image modal behavior
- `commandPalette.js` - Handles the ctrl/cmd k command palette

## Features

- Dynamic image modal viewer for dev work and project screenshots
- Clean, mobile-responsive design, with a simple UI built from scratch

## Notes

- No frameworks used, pure frontend.
- Hosted on GitHub Pages.
